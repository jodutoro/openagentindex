About the Open Agent Index

Open Agent Index is run by Jonathan Duque, who is also the named author of its method. He has worked with businesses since 2017. The index is a separate research project for owners who need to choose tools for a real business job, not a directory built to push a vendor or a service.

The useful thing about a dated index is that it tells you when its picture of a project was taken. Software changes. Licences change. Documentation gets rewritten. A score without a collection date asks you to treat a moving target as fixed. Each Open Agent Index edition carries a date, links to the public evidence used for its rows, and a published formula. That gives an owner something they can inspect, question, and compare with a later edition.

Its evidence comes from public project documentation, repository data, licence files, and independent reviews. The score is a structured reading of that evidence for a named business function. It is not a promise that a tool will fit every company. A missing fact stays missing rather than being turned into a confident guess.

The method also puts limits on the index. It has no paid placement and no affiliate links. It does not rank agencies. It will not publish “worst” lists. Those rules matter because a ranking is easier to trust when the commercial incentives and the scope are visible. They also make the limits plain: this is a dated research record, not a substitute for checking a tool against your own data, approvals, costs, and operating habits.

Open Agent Index applies an owner-facing concern to a narrow job: making tool evidence easier to read before a purchase or build decision. Jonathan’s bio and public contact details are available through Jonathan Duque and LinkedIn.

If you find a wrong value, source, or label, use the correction path. Jonathan Duque reviews each request against the cited source; a request does not automatically change a result, and accepted corrections are dated in the change log on the methodology page.

  • Hermes Agent

    Hermes is a self-hosted agent runtime: one gateway process connects an LLM agent with persistent memory, skills, built-in tools, MCP servers, subagents and scheduled jobs to Telegram, Discord, Slack, WhatsApp, Signal, email and other channels, on the operator's own machine, VPS or Docker container. Source

    • Licence: OSI-approved open source
    • Last stable release: v0.23.2, 2026-11-16
    • Install: package, docker

    Not ranked yet: its job is ranked once three other tools qualify.

  • Codex CLI

    Codex CLI is a coding agent from OpenAI that runs in the operator's terminal, edits files and runs commands in a workspace under a sandbox with approval prompts, and can delegate work to subagents and search the web. Source

    • Licence: OSI-approved open source
    • Install: package, binary

    Not ranked: it is built for writing and changing software, which is developer work outside the index's jobs.

  • Beads

    Beads (the bd CLI) gives a business's coding agents a persistent, dependency-aware task graph in a version-controlled Dolt database, so agents can create, claim and close work items across sessions, branches and machines. Source

    • Licence: OSI-approved open source
    • Install: package, binary

    Not ranked: it is a part an AI agent uses, not an agent you hand tasks to, so the index has no job to rank it in.

  • Agent Reach

    Agent Reach installs a CLI and an agent skill that let a business's own AI agent read and search platforms such as Twitter/X, Reddit, YouTube, GitHub, Bilibili and Xiaohongshu without paid platform APIs, and 'agent-reach doctor' reports each channel's status. Source

    • Licence: OSI-approved open source
    • Install: package

    Not ranked: it is a part an AI agent uses, not an agent you hand tasks to, so the index has no job to rank it in.

  • HyperFrames

    HyperFrames gives a business's own coding agents (Claude Code, Codex, Cursor, Gemini CLI) 21 skills, a CLI, a browser editor and a renderer, so the agent can write HTML-based video projects and render them to MP4 on the operator's machine. Source

    • Licence: OSI-approved open source
    • Install: package, binary

    Not ranked: it is a part an AI agent uses, not an agent you hand tasks to, so the index has no job to rank it in.

  • qmd

    qmd indexes a business's markdown notes, meeting transcripts and documents on the local machine and returns ranked documents for keyword or semantic queries, using local GGUF models for query expansion and re-ranking, through a CLI, an MCP server and an SDK that the business's agents call.
