Back office: agent tools, ranked

Invoices, documents and internal admin.

Method by Jonathan Duque

These scores are research-based: public documentation, repository data, licence files and independent reviews, collected on 2026-11-18. No hands-on tests have been run yet; the planned protocol is on the methodology page.

Back-office automation earns its keep by taking repetition out of work that still needs a paper trail. The owner hands off a defined preparation job: read supplier invoices, pull out the vendor, date, total and tax, then prepare an entry for review. The system may route a record, attach the source document, or ask for missing information. It should not post the transaction merely because an extracted number looks tidy.

The failure that costs money is a bad entry that reaches the books. A missed tax amount, a transposed total, or a duplicate invoice can distort cash planning and create a reconciliation problem. Access is part of the risk too. An agent with write access to invoices, payments, or a ledger can do damage quickly if the workflow has no pause before the irreversible step.

Approval is therefore the first owner-fit question for this function. It should stop a prepared entry before posting and show the source document beside the proposed values. Data boundary is close behind: invoices contain supplier identities, bank details, addresses, and commercial terms. Setup burden matters because a back-office flow must handle file formats, OCR, permissions, retries, and an accounting-system connection. Running cost includes hosting, storage, OCR, and model use. Licence clarity matters when the workflow becomes part of the company's operating system, not just a trial.

Kestra's documented expense example pauses for manager approval before payment processing. n8n's template library includes an invoice validation and approval workflow, and Windmill documents flow approvals and agent-tool approval. Invoice Ninja exposes invoice records through an API, but the collected evidence does not document a review step. Paperless-ngx documents document ingestion and optional AI suggestions, with those AI features disabled by default. These details describe different handoff points, not interchangeable features.

Seven tools are ranked for back office. The evidence shows documented job fit, owner-fit fields, repository health, licence classification and qualifying independent reviews. It does not show extraction accuracy on ten invoices, duplicate detection, accounting reconciliation, or whether an approval can be bypassed by a retry. The planned protocol will use sample supplier invoices and require every entry to post only after approval. Until then, a person should approve every value and every write.

The ranked licence labels are: 3 OSI-approved open source; 1 Fair-code; 1 Source-available; 2 Mixed licence. 3 of 7 ranked tools document a human-approval step that works in the free self-hosted edition. Invoice Ninja has no built-in AI feature in the sources collected; an agent would drive it through its API. Node-RED has no built-in AI feature in the core product; AI agents come as community nodes. 9 independent reviews are counted across these rows.
