Setup
PHP application (PHP 8.2+, MySQL): clone and composer install, or download a release (no composer needed); a Docker image (docker-standalone) and DigitalOcean one-click app are also available. Sources: github.com
Approval
Not documented as of 2026-11-19
Data
Self-hosted on the operator's server (PHP/MySQL), so chat data stays on the operator's infrastructure; AI is integrated by connecting the operator's own provider (OpenAI, Ollama, Gemini, Rasa). Sources: github.com, livehelperchat.com
Cost
Free to self-host (Apache-2.0); the homepage states 'Enterprise level features free to use for everyone everywhere'. Sources: livehelperchat.com, github.com
