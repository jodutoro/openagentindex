    Owner fit
    Setup
    Install the Node.js CLI (npm install -g @hexabot-ai/cli, Node.js 24.22.1 or later), run hexabot create, answer an interactive admin-credential prompt, then hexabot dev; Docker-based services are optional and the CLI has a --docker mode; SQLite by default, Postgres for production. Sources: docs.hexabot.ai, github.com
    Approval
    Not documented as of 2026-11-19
    Data
    Self-hosted: the project states you keep production data under your control, with SQLite or Postgres as the database; model calls go to whichever AI provider or MCP server you configure. Sources: hexabot.ai, github.com
    Cost
    Community edition is self-hosted and free with no licence key but limited to 1 user and 10 workflows; paid licence-key plans are Starter $19/month (3 users, 25 workflows), Pro $59/month (10 users, 150 workflows) and Unlimited $149/month (25 users), with no per-message billing. Sources: hexabot.ai
