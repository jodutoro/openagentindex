Where it is ranked

  • Customer support: rank 1, score 100.0. Zammad is a web-based helpdesk for customer communication across email, chat, telephone and social media, and its current product documentation describes AI agents, ticket summaries and AI-assisted replies.

Owner fit

Setup
Docker Compose deployment requires cloning the compose repository, at least 4 GB RAM and Elasticsearch host tuning. Sources: docs.zammad.org
Approval
yes — the AI Writing Assistant shows the agent the original text beside the AI suggestion and inserts it only after the agent clicks Approve. AI features are optional and need an AI provider; a self-hosted install can use its own (OpenAI, Anthropic, Mistral, Ollama or an OpenAI-compatible endpoint), while Zammad's pricing page says AI usage on its own plans is billed at EUR 0.03 per AI call. AI agents configured by an admin can change tickets without an approval step. Sources: user-docs.zammad.org, admin-docs.zammad.org, admin-docs.zammad.org, zammad.com
Data
Self-hosted Zammad runs on the operator's servers; external AI-provider use is optional, and a local LLM can keep AI processing on the operator's infrastructure. Sources: zammad.com, zammad.com
Cost
Self-hosted software is AGPL; optional self-hosted support packages start at €2,999/year, while hosted plans start at €7/agent/month billed annually (seen 2026-11-18). Sources: zammad.com
