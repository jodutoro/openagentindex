Where it is ranked

  • Back office: rank 9, score 70.5. ERPNext is Frappe's ERP for accounting, invoicing, procurement and stock, and the built-in MCP server in Frappe Framework v16 lets an external AI client find DocTypes and methods, read and change documents, and call whitelisted methods under the signed-in user's permissions.

Owner fit

Setup
Docker (frappe_docker pwd.yml for evaluation only; the README says to expect to throw that environment away) or a manual bench install with MariaDB and Redis; production Docker setup and custom apps need the full frappe_docker documentation. The MCP server needs Frappe v16 or later plus OAuth set up on the site. Sources: github.com, docs.frappe.io
Approval
no — MCP tools apply the signed-in user's permission checks, but no approval step is documented for MCP writes; the frappectl command-line client 'does not ask for confirmation' (the caller or agent harness must confirm), though a new frappectl profile is read-only until made writable. Sources: docs.frappe.io
Data
Self-hosted: ERPNext records stay on the operator's server. The built-in MCP endpoint (/api/v2/mcp) is on by default for new sites and works for the MCP client you choose, signed in through OAuth or an API token; whatever that client retrieves goes to that client's AI provider. Sources: docs.frappe.io
Cost
Free to self-host (GPL-3.0, no per-user fee). Frappe Cloud hosting: sites from $5/month and servers from $20/month, as shown on the ERPNext pricing page on 2026-11-18. Sources: frappe.io, raw.githubusercontent.com
