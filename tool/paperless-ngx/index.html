Where it is ranked

  • Back office: rank 7, score 66.0. Paperless-ngx ingests and OCRs documents into a searchable archive, supports document metadata, workflows and REST API uploads, and officially documents optional AI/LLM suggestions, document chat and similar-document retrieval; these AI features are disabled by default.

Owner fit

Setup
The recommended path is an interactive Docker Compose installation script; manual Docker Compose is medium effort, while bare-metal installation requires Python, OCR, database and Redis-compatible dependencies. Sources: docs.paperless-ngx.com

Not documented as of 2026-11-18
Data
Documents and application data are stored locally on the operator's server and are not transmitted unless explicitly chosen; optional Azure remote OCR or LLM features can send selected processing to configured external providers. Sources: paperless-ngx.com, docs.paperless-ngx.com
