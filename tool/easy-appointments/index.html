Where it is ranked

  • Scheduling and intake: rank 2, score 75.5. Easy!Appointments is a self-hosted appointment scheduler with a REST API and configurable webhooks that POST booking, customer, provider and related changes to external systems; no built-in AI feature is documented in the official documentation. No built-in AI: an agent drives it through its API

Owner fit

Setup
The administrator documentation covers installation on your own server, Docker and updates; the release requires a PHP web server and MySQL-compatible database. Sources: easyappointments.org, easyappointments.org
Approval
Webhook configuration is restricted to system administrators, but no human approval gate for bookings or automation is documented. Sources: easyappointments.org
Data
Appointments, customers and notes stay in the operator's own database/server; webhooks intentionally send selected event payloads to URLs chosen by the operator. Sources: easyappointments.org, easyappointments.org
Cost
Self-hosted software is free with no license fee; official managed hosting is €20/month billed annually (seen 2026-11-18). Sources: easyappointments.org
