Owner fit
Setup
Python 3.11+ install (pip install -e . in a virtualenv) with a signed-in Claude Code CLI (Claude Pro or Max) or a ChatGPT plan with the Codex CLI, a sending mailbox (Gmail, Microsoft 365 or SMTP) and warmup; a Docker Compose setup is documented for native Linux only, and the README offers a Claude Code guided setup. Sources: github.com, github.com
Approval
yes — every outgoing email, including drafted replies, waits in the Outbox for a person's approval until the owner switches on autopilot; this is the default in the free self-hosted app. Sources: github.com, github.com
Data
Runs on the operator's own machine or server with its database and logs in a local data folder and a dashboard bound to 127.0.0.1; model calls go through the operator's own Claude Code or Codex subscription, and Docker is documented for native Linux only. Sources: github.com, github.com
Cost
Software is free (AGPL-3.0); no model API bill because it runs on an existing Claude Pro/Max or ChatGPT plan; finding businesses is $0 on the default OpenStreetMap source (paid sources from about $0.37 per 1,000), and a Google Workspace mailbox is about $7 a month (README, as seen 2026-11-18). Sources: github.com
