Where it is ranked

  • Reporting and content: rank 7, score 72.0. Metabase's AGPL edition includes Metabot, an AI agent that answers natural-language questions about your data and lets you open the query behind each chart it builds; self-hosters connect their own AI provider key in Admin > AI.

Owner fit

Setup
One Docker container (docker run metabase/metabase) or a JAR; for production, provision a Postgres database for Metabase's application data. Sources: metabase.com
Approval
No workflow approval gate documented. Metabot sees only what the signed-in person can see, and docs recommend double-checking AI results; the query behind each answer can be inspected. Sources: metabase.com, metabase.com
Data
Self-hosted: queries run in your warehouse and the app stays on your server. With your own AI key, the same data goes to the provider you chose; Metabase's own AI service is Cloud-only. Sources: metabase.com, metabase.com
Cost
Metabase's AGPL edition is free with unlimited users (AI: bring your own model, no Metabase AI fee). Cloud Starter $100/month for 5 users plus $6 per extra user; Enterprise from about $20,000/year (pricing page, 2026-11-18). Sources: metabase.com, metabase.com
Community
50,391 GitHub stars (2026-11-18); community forum is the open-source support channel. Sources: api.github.com, metabase.com
