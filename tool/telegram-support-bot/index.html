Telegram Support Bot turns each Telegram or Signal message into a ticket in a staff group, and an optional LLM integration answers common questions automatically from a knowledge base the operator provides, with AI triage (category, priority, summary, sentiment) and translation of staff replies.

Owner fit
Setup
Docker Compose (copy config/config-sample.yaml to config.yaml and set bot_token/staffchat_id/owner_id, then docker compose up -d, which starts the bot, MongoDB 8, signal-cli and optionally mongo-express), or Node.js 24+ with a MongoDB instance (npm ci, npm run build, npm run prod). Sources: github.com
Approval
Not documented as of 2026-11-19
Data
Self-hosted: the bot, tickets and MongoDB run on the operator's infrastructure, and the LLM connects to OpenAI or any OpenAI-compatible endpoint (LiteLLM, Ollama, vLLM) the operator configures, so ticket data can stay local. Sources: github.com
Cost
Free to self-host (GPL-3.0). Hosted 'Botspace' service from EUR 4.99/month (Starter), EUR 9.99/month (Pro, includes AI answers beta) and EUR 19.99/month (Business), seen 2026-11-18. Sources: botspace.bostrot.com, github.com
