Where it is ranked

  • Customer support: rank 1, score 94.8. Dify's docs include a tutorial, "Customer Service Bot With Knowledge Base", that builds a Chatflow answering customer questions from an imported knowledge base and embeds it on a website; the same docs describe chatbots, chatflows and agents on a visual canvas, published as a web app, a website embed or an API.
  • Reporting and content: rank 1, score 94.8. Dify's Human Input node pauses a workflow so a person can review AI-generated content and choose Approve, Regenerate or similar branches before it is published; the docs include a Content Review Workflow example.

Owner fit

Setup
Docker Compose: clone a release, copy .env.example to .env, bring up the stack (nginx on port 80 by default). A third-party review states it needs Docker Compose v2.24.0+, at least 2 CPU cores and 4 GiB RAM. Sources: docs.dify.ai, heybotify.com
Approval
Yes: the Human Input node pauses a workflow and sends a form (web app or email) to a named person with decision buttons (e.g. approve/regenerate/forward) and a timeout branch; an API integration flow for it is documented. Sources: docs.dify.ai, docs.dify.ai
Data
Self-hosted Community Edition keeps apps, knowledge and logs on your server; prompts go to whichever model providers you configure. Dify Cloud plans include message credits for hosted models. Sources: docs.dify.ai, dify.ai
Cost
Self-host free (infrastructure and model API costs are yours). Cloud (seen 2026-11-18 on dify.ai/pricing): Professional $590 per workspace per year, Team $1,590 per workspace per year. Sources: dify.ai
Community
About 160k GitHub stars (2026-11-18); the docs link a Discord server. Sources: docs.dify.ai
