Node-RED

Collected

Where it is ranked

  • Back office: rank 4, score 77.5. Node-RED is a browser-based flow editor with a palette of over 5,000 community nodes; AI agents are not in the core product but exist as community nodes (for example node-red-contrib-ai-agents, built on LangChain.js and LangGraph with MCP tool support), so back-office flows can wire LLM steps into HTTP, email, database and file nodes. No built-in AI in the core product: AI agents come as community nodes

Owner fit

Setup
One Docker container or an npm install of a single Node.js process; no separate database needed. The editor is not secured by default: anyone who can reach it can deploy changes until you configure adminAuth. Sources: nodered.org, nodered.org, browserless.io
Approval
No human-in-the-loop or approval step documented in the core product pages; any approval gate would be built by hand or via a community node. The AI agent nodes are marked beta. Sources: nodered.org, flows.nodered.org
Data
Self-hosted: flows are stored on your server and data goes only where the flow sends it; any LLM node sends prompts to the provider you configure. Sources: nodered.org, flows.nodered.org
Cost
Free self-host. A third-party estimate puts a small VPS at about $5-7/month; the managed option is FlowFuse Cloud (no price published). Sources: altaitools.com
Community
23,840 GitHub stars (2026-11-18); nodered.org states over 5,000 community nodes and flows. Sources: api.github.com, nodered.org
