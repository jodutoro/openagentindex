Setup
Quick install is a one-command bootstrap; the recommended self-host deployment is Docker Compose with PostgreSQL and Redis, while Kubernetes uses a Helm chart. Sources: activepieces.com
Approval
no — paid plan only: Flow Approvals is an Enterprise/Cloud feature requiring the Environments plan. Sources: activepieces.com
Data
Activepieces documents running on your own infrastructure, bringing your own AI keys, and controlling which apps/models see data and where credentials live; its cloud pricing page also offers cloud or on-prem hosting. Sources: activepieces.com, activepieces.com
Cost
Core self-hosting is free under MIT; cloud pricing seen 2026-11-18 is Free $0, Plus $20/month, Team $200/month, Ultimate custom, and Embed from $36,000/year. Sources: activepieces.com, activepieces.com
