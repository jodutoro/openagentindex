Where it is ranked

  • Customer support: rank 5, score 70.3. Typebot's docs describe a chatbot builder for conversational apps including customer support, deployable on a website or WhatsApp; its FAQ says live chat is not native and human takeover is done by hitting the Chatwoot block.
  • Lead follow-up: rank 5, score 65.0. Typebot's docs list lead qualification as a use case; flows chain input blocks (text, email, buttons), logic blocks and integration blocks (webhooks, OpenAI) and collect results in real time.
  • Scheduling and intake: rank 3, score 70.3. Typebot ships Date and Time input blocks that let a conversational flow collect booking details before passing them on via integration blocks or webhooks; it is an intake front end, not a calendar or availability engine.

Owner fit

Setup
Self-hosting guide in the docs: two apps, the builder and the viewer, plus a Postgres database; deployment guides cover Docker, Vercel and a manual install. The docs say the managed cloud saves substantial developer time. Sources: docs.typebot.com
Approval
No approve-before-send step is documented. FAQ: live chat is not native; human takeover is available through the Chatwoot block. Sources: docs.typebot.com
Data
Self-hosted: builder, viewer and results database run on your server. AI blocks send prompts to the LLM provider whose API key you configure (bring your own LLM). Sources: docs.typebot.com, docs.typebot.com, chatbotscape.com
Cost
Self-host: no licence fee for internal use (infrastructure and LLM API costs are yours). Cloud (seen 2026-11-18): Free 200 chats/month, $39/month Starter (2,000 chats), $89/month (10,000 chats). Sources: typebot.com
Community
About 11k GitHub stars (2026-11-18); 3,000+ members on Discord as published on typebot.com. Sources: typebot.com
