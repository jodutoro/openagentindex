Where it is ranked

  • Reporting and content: rank 8, score 70.5. Huginn's Digest Agent collects incoming events into a single scheduled digest event, its Email Digest Agent emails the collected events, its Data Output Agent publishes events as an RSS or JSON feed, and its OpenAI LLM Agent sends chat-completion requests to any OpenAI-compatible API, which the README lists for summarizing and classifying text.

Owner fit

Setup
Single Docker container (docker run -p 3000:3000 ghcr.io/huginn/huginn) for evaluation; the official Docker guide also covers an external MySQL or PostgreSQL database, a multi-process image with separate web and worker containers, and Dokku. The local-development path needs Ruby, Node.js and MySQL or PostgreSQL. Sources: github.com, github.com
Approval
Not documented as of 2026-11-18
Data
Self-hosted: the README states you always know who has your data, because Huginn runs on your own server. Data leaves the box only through agents you configure; the OpenAI LLM Agent sends its rendered message to the configured OpenAI-compatible API base URL (default https://api.openai.com/v1, or a local endpoint such as Ollama at http://localhost:11434/v1). Sources: github.com, github.com
Cost
Free to self-host under the MIT licence; the operator pays for their own server and, if OpenAI agents use a hosted provider, that provider's API charges (not priced here). No hosted Huginn cloud plan was found in the fetched first-party sources. Sources: raw.githubusercontent.com, github.com

GitHub repository: 50,572 stars as of 2026-11-18; the README points questions to GitHub Discussions. Sources: api.github.com, github.com
