Where it is ranked

  • Reporting and content: rank 1, score 94.8. AnythingLLM Docker is a multi-user server where teams chat with their private documents (RAG) and use agents with tools, MCP and no-code Agent Flows; workspaces have access control and chat widgets can be embedded.

Owner fit

Setup
Docker image for a multi-user server (or a one-click desktop app for single users); the docs state either can use local LLMs, RAG and agents with little configuration. Sources: docs.anythingllm.com
Approval
Yes: risky agent tool calls show an Approve/Reject card; the request times out and is rejected after 2 minutes by default, and admins can auto-approve chosen skills with AGENT_AUTO_APPROVED_SKILLS. Sources: docs.anythingllm.com, docs.anythingllm.com
Data
Self-hosted Docker keeps documents and chats on your server and supports any LLM and vector database; Desktop keeps everything on the device. Cloud LLM calls go to the provider you configure. Sources: docs.anythingllm.com, anythingllm.com
Cost
Self-host free (MIT; model API costs are yours). Hosted (seen 2026-11-18): Basic $50/month, Pro $99/month, Enterprise custom with on-premise deployment. Sources: anythingllm.com
Community
68,385 GitHub stars (2026-11-18); homepage publishes 67k+ stars, 200+ contributors and 5M+ Docker pulls. Sources: api.github.com, anythingllm.com
