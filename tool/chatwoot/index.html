Where it is ranked

  • Customer support: rank 7, score 77.3. Chatwoot provides a shared omnichannel inbox for website, email, social and messaging conversations, with Captain AI for drafted replies and routine-question resolution plus APIs and webhooks for automation.

Owner fit

Setup
Docker, Linux VM, Kubernetes, or cloud deployment; the official guide describes Docker as medium complexity and Kubernetes as high. Sources: github.com
Approval
no — paid plan only: Captain AI (an assistant that hands off to a person, plus Copilot, which helps agents summarize and draft replies) is not included in the free Community Edition; it comes with the self-hosted Premium Support ($19 per agent per month) or Enterprise Edition ($99 per agent per month) plans. Sources: chatwoot.com, chatwoot.com, chatwoot.com
Data
Self-hosting keeps customer-support data on the operator's infrastructure; cloud or external AI integrations are optional. Sources: github.com, chatwoot.com
Cost
Self-hosted Community Edition: $0, free forever. Self-hosted paid plans: Premium Support $19 per agent per month, Enterprise Edition $99 per agent per month. Chatwoot Cloud: Hacker $0, Startups $19, Business $39, Enterprise $99 per agent per month; extra Captain AI credits $20 per 1,000 (prices seen 2026-11-18). Sources: chatwoot.com, chatwoot.com
