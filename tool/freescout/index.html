Where it is ranked

  • Customer support: rank 6, score 79.3. FreeScout is a self-hosted shared-inbox help desk (a Help Scout and Zendesk alternative, per its GitHub description) whose free official AI Integration module drafts replies, summarizes conversations and fixes spelling and tone using an AI provider the owner configures, including local Ollama or LM Studio models.

Owner fit

Setup
PHP 7.4 to 8.x with MySQL, MariaDB or PostgreSQL behind Nginx, Apache or IIS, with no stated minimum CPU or RAM; the wiki guide installs on Ubuntu with git clone, cron and HTTPS, and a Docker image is listed. A mailbox account is needed to fetch email. Sources: github.com, github.com
Approval
Not documented as of 2026-11-18
Data
Self-hosted: tickets stay on the operator's server. The AI Integration module sends requests to whichever AI provider the operator configures; local providers (Ollama, LM Studio) are among the supported options. Sources: freescout.net, github.com
Cost
Free to self-host (AGPL-3.0 core, no licence fee); the AI Integration module is free, and the operator pays the chosen AI provider's usage. Most other official modules are lifetime licences for a single FreeScout instance, all payments non-refundable (freescout.net/modules, seen 2026-11-18). Sources: freescout.net, freescout.net
Community
GitHub repository: 4,671 stars; freescout.net links a Forum and a Feature Requests page (no member counts seen on the pages read). Sources: api.github.com, freescout.net
