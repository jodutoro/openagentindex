Owner fit
Setup
Install by cloning or uploading the release archive to a PHP 8.3+ host with MySQL 8.0+, set the document root to public/, and run the setup wizard; no Composer, npm or Node.js is required on the server. Sources: voxelbooking.com, github.com
Approval
yes — customer bookings and protected staff changes use preview and review steps before a commit; the customer or staff member approves in VoxelBooking. Sources: voxelbooking.com, voxelbooking.com
Data
VoxelBooking stores booking records on the operator's PHP server and has no AI built in. A customer books through an AI client of their own over the Agent API (HTTP or MCP), so the booking details they give (contact details, date, party or guest count) reach whichever AI client they connect; a public booking connection cannot read existing customer records. Sources: voxelbooking.com, voxelbooking.com, voxelbooking.com
Cost
The software is free and open source with no subscription, per-booking commission or per-seat fee; the operator pays for hosting, email delivery, server administration and backups. Sources: voxelbooking.com
