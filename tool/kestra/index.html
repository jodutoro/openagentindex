Where it is ranked

  • Back office: rank 1, score 89.5. Kestra runs declarative YAML workflows with an AIAgent task, and its docs and examples show an agent evaluating an expense report against policy then pausing for a manager's approval before payment processing continues.

Owner fit

Setup
Docker Compose with a PostgreSQL backend: download the compose file, run docker compose up -d, UI on port 8080. Production use is a more technical job than a no-code tool. Sources: kestra.io, futurepicker.com
Approval
Yes: the Pause task halts an execution until someone resumes it from the UI or API and records the decision and a comment; the Enterprise HumanTask plugin adds assignment to named users or RBAC groups. Sources: kestra.io, kestra.io
Data
Self-hosted: flows, executions and queue (PostgreSQL or MySQL in open source) stay on your infrastructure; AIAgent tasks call the LLM provider you configure with your own API secret. Sources: kestra.io, kestra.io
Cost
Open source edition free with unlimited flows and executions. Kestra Cloud and Enterprise Edition (annual, per instance) are priced by sales or usage; no list prices are published (checked 2026-11-18). Sources: kestra.io
Community
30,248 GitHub stars (2026-11-18); kestra.io announces crossing 30,000 stars. Sources: api.github.com, kestra.io
