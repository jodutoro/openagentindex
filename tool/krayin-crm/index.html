Where it is ranked
  • Lead follow-up: rank 11, score 75.5. Krayin is a Laravel CRM with a lead pipeline, logged calls, meetings and notes so follow-ups are not missed, and a built-in Magic AI feature that reads an uploaded PDF (such as an invoice or business card) and creates a pre-filled draft lead using an OpenRouter model the owner sets up with their own API key; Krayin's developer docs list image OCR as planned.
    Score breakdown: Research evidence 75 × 0.35; Owner fit 60 × 0.3; Project health 85 × 0.25; Licence clarity 100 × 0.1.
Owner fit
Setup
Apache 2 or Nginx (with PHP-FPM) on a server with PHP 8.3+, Composer 2.5+, 3 GB RAM or more, and MySQL 8.0.32+ or MariaDB 11.4+; installed with composer create-project and php artisan krayin-crm:install, a browser installer, or Docker. Sources: devdocs.krayincrm.com, devdocs.krayincrm.com
Approval
no — Magic AI creates the lead record directly Sources: devdocs.krayincrm.com
Data
Self-hosted: CRM data stays on the operator's server. Magic AI sends the parsed uploaded file to the OpenRouter model chosen in Settings > Configuration > General > Magic AI, so file content leaves the server for that call. Sources: devdocs.krayincrm.com, docs.krayincrm.com
Cost
Free to self-host (MIT, no licence fee). Magic AI calls use the owner's own OpenRouter API key and are billed by OpenRouter (rates not fetched). Official Krayin CRM Hosting is advertised at $20/month with unlimited users on the Krayin site, as seen on 2026-11-18. Sources: github.com, docs.krayincrm.com, krayincrm.com
Community
Krayin provides a community forum for questions and discussion. Sources: forums.krayincrm.com
