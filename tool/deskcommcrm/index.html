Owner fit
Setup
Needs a Docker-capable VPS (4 GB RAM recommended), a Supabase project (the installer can create one) and an OpenRouter, Anthropic or OpenAI key; the install.sh script pulls prebuilt images and starts about seven containers with automatic HTTPS. Sources: deskcomm.com.br, github.com
Approval
no — replies are sent by the agent after automated checks, not held for a person; a person approves only changes to the agent's own configuration (Proposals) Sources: github.com, deskcomm.com.br
Data
Data stays on the operator's own VPS and Supabase project; prompts go to the AI provider the operator selects (OpenRouter, Anthropic or OpenAI); Sentry error reporting is opt-in at install. Sources: github.com, deskcomm.com.br
Cost
MIT licence with no paid version; the operator pays for the VPS, a Supabase project and the AI provider's usage. Sources: deskcomm.com.br, github.com
