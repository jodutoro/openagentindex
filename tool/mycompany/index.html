Evidence

Where it is ranked
  • Back office: rank 11, score 71.3. MyCompany is an open-source ERP whose Bills screen has an Import (GPT) action that reads a supplier document file with OpenAI and fills the bill's header (number, dates, vendor, currency) and lines (item, quantity, price, taxes) from existing master data, leaving the bill in Draft for a person to review and correct before it is marked To pay.
    Score breakdown: Research evidence 50 × 0.35; Owner fit 100 × 0.3; Project health 55 × 0.25; Licence clarity 100 × 0.1.
Owner fit
Setup
Docker Compose with four containers (PostgreSQL, application server, MyCompany, web client) from a compose.yaml on the lsFusion download server, or a Linux install script or Windows installer; 4 GB RAM recommended; the GPT bill import also needs an OpenAI API key and a recognition prompt on the bill type. Sources: mycompany-docs.lsfusion.org, github.com, github.com
Approval
yes — an imported bill is created as a Draft that a person reviews and adjusts, and it moves to To pay only through the Mark as Todo action; values that cannot be matched to existing master data stay empty. Sources: github.com
Data
ERP data stays in the operator's own PostgreSQL; only the supplier document sent for GPT import goes to OpenAI, using the operator's own API key, and the import is skipped with a message if the key or request fails. Sources: github.com, github.com, mycompany-docs.lsfusion.org
Cost
Apache-2.0 with no licence fees; the operator pays for the server and for OpenAI API usage on GPT imports. Sources: mycompany.lsfusion.org, github.com
