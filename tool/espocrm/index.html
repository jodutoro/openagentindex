Where it is ranked

  • Lead follow-up: rank 5, score 79.3. EspoCRM captures leads through web forms or its API and converts them to accounts, contacts or opportunities; round-robin or least-busy assignment and follow-up emails and tasks run from Workflows, which need the paid Advanced Pack extension; its free official MCP extension lets AI agents read and write CRM records through tools an admin chooses.

Owner fit

Setup
Docker (docker run or Docker Compose, with MariaDB and a daemon container) or the install-by-script option that sets up Docker, Nginx and MariaDB; manual install on a PHP/MySQL server also documented. The MCP extension is installed by uploading its package under Administration > Extensions, and the MCP client must support protocol version 2026-07-28. Sources: docs.espocrm.com, docs.espocrm.com, espocrm.com
Approval
no — not for the free MCP extension, which documents admin-chosen tools and a per-endpoint user list but no approval step. User-review steps are documented only in the Intelligence extension, whose price is not published on the fetched first-party pages: Intelligent Paste lists extracted fields so the user can uncheck them, and AI Email Composer text is copied into the email only when the user clicks Apply. Sources: github.com, docs.espocrm.com
Data
Self-hosted: CRM data stays on the operator's server. The MCP extension runs inside the instance through its REST API; admins pick which tools and fields are exposed and which users may connect, and what an agent retrieves goes to that agent's AI provider. The Intelligence extension sends the record name, description and stream history to the configured provider (OpenAI, Gemini, Claude or a custom OpenAI-compatible endpoint). Sources: espocrm.com, github.com, docs.espocrm.com
Cost
Free to self-host (AGPL-3.0 core; the official MCP extension is 'distributed for free'). EspoCRM Cloud, seen 2026-11-18: Basic $15 per user per month (minimum 3 users), Enterprise $25 (minimum 5), Ultimate $69 (minimum 10). Self-host prices for the Advanced Pack and Intelligence extensions are not published on the fetched first-party pages. Sources: espocrm.com, espocrm.com, espocrm.com
Community
GitHub repository: 3,638 stars; the README points users to the community forum for help. Sources: api.github.com, raw.githubusercontent.com

Licence

OSI-approved open source GNU Affero General Public License v3.0 or later. The repository LICENSE.txt is the AGPLv3 text and the README says EspoCRM is licensed under GNU AGPLv3. Paid extension packs (for example the Advanced Pack with workflows) are separate downloads sold on espocrm.com and are not in the repository. Under espocrm.com's Extension License Agreement (version 1.1), a paid extension may be used on a single EspoCRM instance on a single server for the licensed period, and the licence must be renewed or bought again when that period ends; the official MCP extension is a separate AGPL-3.0 repository (espocrm/ext-mcp).
