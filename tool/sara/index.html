Setup
Docker Compose: git clone, copy .env.example to .env and set GROQ_API_KEY (or another provider), then docker compose up -d; connect WhatsApp by scanning a QR code. Sources: github.com
Approval
Not documented as of 2026-11-18
Data
Self-hosted: the agent, PostgreSQL/pgvector RAG index and configuration run on the operator's infrastructure; PII is anonymised before any external LLM call, and autonomy is configurable (OFF/OBSERVE/SEMI-AUTO/FULL-AUTO). Sources: github.com
Cost
Free to self-host (AGPL-3.0). A cloud version exists at get-scala.com; no plan prices were on the fetched pages. Sources: github.com
