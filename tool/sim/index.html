Where it is ranked

  • Customer support: rank 5, score 80.5. Sim's Zendesk and Intercom integrations let a workflow agent read, create, update and search support tickets and conversations (Intercom's page names support triage and follow-up), and a workflow can be deployed as a hosted chat page with its own access control.
  • Lead follow-up: rank 4, score 80.5. Sim's HubSpot integration reads and updates CRM contacts, companies, deals and tickets and starts workflows from HubSpot events, and Sim's sales page describes agents for lead research, outreach, follow-up and CRM updates.
  • Back office: rank 6, score 80.5. Sim's finance page describes agents for invoice processing, reconciliation and recurring reports with approval routing, its QuickBooks integration reads and updates QuickBooks Online records, and its Human block can pause a run for a person to review or correct extracted data.

Owner fit

Setup
Docker Compose single node through the 'bunx sim-setup' wizard (needs Docker with Compose 2.24+, Bun and Node.js 20+; bundles PostgreSQL with pgvector, Redis and a scheduler), or a Helm install on Kubernetes; the docs give 2 CPU cores, 12 GiB RAM and 20 GiB SSD as an evaluation example and 4 cores, 16 GiB and 50 GiB for a team, and ask for TLS, email, object storage and backups to be configured before production use. Sources: docs.sim.ai, docs.sim.ai
Approval
yes — the Human block pauses a run until a person submits an approval, feedback or corrected data, with notifications through Slack, Gmail, Microsoft Teams, Twilio SMS or a webhook and no automatic timeout; the docs page and the pricing feature table state no plan restriction, and the block's source sits in apps/sim/blocks, outside the licensed ee directory. Sources: docs.sim.ai, sim.ai
Data
Self-hosted: workspace data, tables, knowledge bases and run logs stay in your own PostgreSQL and storage, with credentials encrypted by keys you hold. Model calls go to whichever provider you configure (OpenAI, Anthropic, Google Gemini, Groq and others), so prompts leave the server unless you point Sim at a local model through Ollama or vLLM. Sources: docs.sim.ai, docs.sim.ai, docs.sim.ai
Cost
Free to self-host under Apache 2.0 (Docker Compose or Kubernetes); enterprise features in apps/sim/ee need a licence. Sim Cloud has Free, Pro, Max and Enterprise plans, with 1,000 one-time credits on Free and one credit worth $0.005 (pricing page seen 2026-11-18); dollar prices for Pro and Max were not shown in the fetched text. You also pay your chosen model provider for LLM calls. The customer-support and lead-follow-up uses documented here run through Zendesk, Intercom or HubSpot, which are separately priced services. Sources: sim.ai
