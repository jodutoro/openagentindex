Atomic CRM tracks contacts, tasks, notes and a kanban deals pipeline, and its MCP server, powered by Supabase Edge Functions and Supabase OAuth, lets Claude, ChatGPT or Visual Studio Code query the CRM and log notes, create tasks or move a deal under the signed-in user's access rules.

Owner fit
Setup
Developer-grade: fork the repository, install Node 24, Make and Docker, run make install for a local Supabase, then deploy a Supabase backend and a static frontend (the docs use Supabase.com and GitHub Pages and mention self-hosted Supabase); the MCP server also needs the Supabase OAuth server enabled. Sources: marmelab.com, github.com
Approval
Not documented as of 2026-11-19
Data
Data lives in the operator's own Supabase project (hosted by Supabase or self-hosted); the MCP server runs on the same instance and respects the same access rules as users, and the AI client the operator connects chooses its own model provider. Sources: marmelab.com, marmelab.com
Cost
Free and MIT licensed with unlimited users, data and storage; the docs say the free plans of Supabase.com and GitHub Pages are sufficient, and Marmelab sells optional paid setup and development services. Sources: marmelab.com, marmelab.com
