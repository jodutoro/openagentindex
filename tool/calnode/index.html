Calnode

Where it is ranked

  • Scheduling and intake: rank 4, score 70.5. Calnode is a self-hosted booking-page scheduler (one Go binary with SQLite) where visitors pick a free slot, with a native MCP server whose booking tools list event types and free slots and create, get, reschedule and cancel bookings, and an optional bring-your-own-model 'Book by chat' assistant on the booking page.

Owner fit

Setup
One container or one static binary, with the data kept in a single SQLite file and no database server, cache or queue: docker run ghcr.io/calnode/calnode:latest with a data volume, BASE_URL and an encryption key; production wants HTTPS behind a TLS proxy. Built-in video needs a LiveKit endpoint. Sources: calnode.com, raw.githubusercontent.com, github.com
Approval
no — the only documented human step is the OAuth consent screen when an agent connects; no per-booking approval step is documented, and create_booking runs the same booking side effects as the REST API. Sources: github.com
Data
Self-hosted: one deployment is one isolated workspace with its own SQLite data. The chat assistant sees only free/busy windows, never calendar contents, and uses any OpenAI-compatible model endpoint the operator chooses (hosted or self-run); it is off by default. Sources: github.com, calnode.com
Cost
Free to self-host under Apache-2.0 ('nothing is paywalled'); the README says it can run on a $5 server. Optional built-in video needs a LiveKit endpoint (Cloud or self-hosted), and the operator pays any AI model provider they choose. The site also advertises done-for-you setup as a service (price not read). Sources: github.com, calnode.com
