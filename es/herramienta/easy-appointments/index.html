Easy!Appointments es un software autoalojado para agendar citas con una API REST y webhooks configurables que envían por POST a sistemas externos los cambios en reservas, clientes, proveedores y datos relacionados; la documentación oficial no describe ninguna función de IA integrada. Ajuste para dueños
Instalación
La documentación para administradores cubre la instalación en tu propio servidor, Docker y las actualizaciones; la versión requiere un servidor web con PHP y una base de datos compatible con MySQL. Fuentes: easyappointments.org, easyappointments.org
Aprobación
La configuración de webhooks está restringida a los administradores del sistema, pero no se documenta ningún paso de aprobación humana para las reservas ni para la automatización. Fuentes: easyappointments.org
Datos
Las citas, los clientes y las notas permanecen en la base de datos o el servidor del propio operador; los webhooks envían de forma intencional los datos de los eventos seleccionados a las URL que elige el operador. Fuentes: easyappointments.org, easyappointments.org
Costo
El software autoalojado es gratuito y no tiene costo de licencia; el alojamiento administrado oficial cuesta €20/mes, facturado anualmente (visto el 2026-11-18). Fuentes: easyappointments.org
Comunidad
La página de soporte del proyecto documenta un servidor de Discord y un grupo de soporte en Google Groups para consultas. Fuentes: easyappointments.org, discord.com, groups.google.com
