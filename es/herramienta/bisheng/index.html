Ajuste para dueños
Instalación
Docker y Docker Compose (V2): clona el repositorio y ejecuta el instalador oficial `bash docker/install.sh`, que crea el .env, descarga las imágenes e inicia MySQL, Redis, MinIO, OpenFGA, Elasticsearch y Milvus. Fuentes: github.com
Aprobación
sí — BISHENG Workflow admite Human-in-the-loop (una tarea se pausa hasta que una persona responde cuando el agente necesita información que solo ella tiene), y unirse a un espacio de conocimiento, suscribirse a un canal o solicitar permisos de menú puede requerir aprobación mediante flujos y nodos de aprobación personalizables. Fuentes: github.com
Datos
BISHENG se puede desplegar de forma privada (autoalojado); la recuperación de conocimiento devuelve solo los espacios y el contenido de archivos a los que un empleado tiene permiso de acceso, con permisos ReBAC hasta el nivel de un solo archivo, y los administradores controlan el acceso a los modelos y los créditos. Fuentes: github.com
Costo
Código abierto (Apache-2.0), autoalojado sin costo de licencia; los paneles y algunas funciones empresariales (SSO/LDAP, alta disponibilidad, revisión de seguridad del contenido) están en la edición comercial. No se encontraron precios públicos de una nube de autoservicio. Fuentes: github.com, bisheng.ai
