Ajuste para dueños
Instalación
Docker Compose: clona el repositorio bytedesk-docker-compose, copia .env.example a .env y luego ejecuta ./start.sh (inicia MySQL + Artemis + la imagen de la aplicación bytedesk); PostgreSQL/Oracle/RabbitMQ y una variante 'noai' son opciones. Fuentes: github.com
