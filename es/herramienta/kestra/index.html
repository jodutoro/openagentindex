Ajuste para dueños
Instalación
Docker Compose con un backend PostgreSQL: descarga el archivo compose, ejecuta docker compose up -d, interfaz en el puerto 8080. Usarlo en producción es un trabajo más técnico que el de una herramienta sin código. Fuentes: kestra.io, futurepicker.com
Aprobación
Sí: la tarea Pause detiene una ejecución hasta que alguien la reanuda desde la interfaz o la API y registra la decisión y un comentario; el plugin HumanTask de la edición Enterprise añade la asignación a usuarios específicos o a grupos RBAC. Fuentes: kestra.io, kestra.io
Datos
Autoalojado: los flujos, las ejecuciones y la cola (PostgreSQL o MySQL en la edición de código abierto) se quedan en tu infraestructura; las tareas AIAgent llaman al proveedor de LLM que configures con tu propia clave secreta de API. Fuentes: kestra.io, kestra.io
Costo
La edición de código abierto es gratis, con flujos y ejecuciones ilimitados. Kestra Cloud y Enterprise Edition (anual, por instancia) se cotizan a través de ventas o según el uso; no se publican precios de lista (consultado el 2026-11-18). Fuentes: kestra.io
Comunidad
Kestra documenta una comunidad en Slack con un canal #help dedicado al soporte técnico. Fuentes: kestra.io
