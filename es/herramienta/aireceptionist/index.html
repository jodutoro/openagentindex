  • Atención al cliente: posición 28, puntuación 53.8. AIReceptionist atiende las llamadas telefónicas del negocio con un agente de voz de OpenAI Realtime que responde preguntas frecuentes a partir de una base de conocimiento configurable, toma mensajes que se entregan por archivo, correo o webhook, y transfiere llamadas a departamentos.
    Desglose de la puntuación: Evidencia de investigación 50 × 0.35; Ajuste para dueños 50 × 0.3; Salud del proyecto 45 × 0.25; Claridad de la licencia 100 × 0.1.
  • Citas y recepción de clientes: posición 8, puntuación 53.8. Desde la versión 0.2.0 el agente de voz consulta la disponibilidad y agenda citas en Google Calendar, y hace una lista de preguntas de recepción de clientes definida para cada negocio; registra las respuestas y las envía por correo al negocio.

Ajuste para dueños
Instalación
Git clone y pip install -e . con Python 3.11+, un archivo YAML por negocio, una clave de API de OpenAI con acceso a Realtime, un proyecto de LiveKit (Cloud o autoalojado) y un troncal SIP de Twilio o Telnyx con un número de teléfono; se incluye una guía de despliegue en Linux con systemd. Fuentes: github.com, github.com
Aprobación
No documentado al 18 de noviembre de 2026
Datos
El agente corre en tu servidor; el audio de las llamadas lo procesa la API Realtime de OpenAI y lo transporta LiveKit; los mensajes van a archivos locales, correo o un webhook, y las grabaciones opcionales van al disco local o a un bucket compatible con S3, con un aviso de consentimiento hablado al inicio. Fuentes: github.com, github.com
Costo
Software AGPL gratuito sin tarifa de plataforma; los costos son el uso de OpenAI Realtime, LiveKit (plan Cloud o tu propio servidor) y las tarifas del troncal SIP y del número de teléfono, que se explican en la sección de gestión de costos de la guía. Fuentes: github.com, github.com
