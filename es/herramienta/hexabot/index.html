    Ajuste para dueños
    Instalación
    Instala el CLI de Node.js (npm install -g @hexabot-ai/cli, Node.js 24.22.1 o posterior), ejecuta hexabot create, responde a la solicitud interactiva de credenciales de administrador y luego hexabot dev; los servicios basados en Docker son opcionales y el CLI tiene un modo --docker; SQLite por defecto, Postgres para producción. Fuentes: docs.hexabot.ai, github.com

    Datos
    Autoalojado: el proyecto afirma que conservas el control de los datos de producción, con SQLite o Postgres como base de datos; las llamadas a modelos van al proveedor de IA o al servidor MCP que configures. Fuentes: hexabot.ai, github.com
    Costo
    La edición comunitaria es autoalojada y gratuita, sin clave de licencia, pero limitada a 1 usuario y 10 flujos de trabajo; los planes de pago con clave de licencia son Starter $19/mes (3 usuarios, 25 flujos de trabajo), Pro $59/mes (10 usuarios, 150 flujos de trabajo) y Unlimited $149/mes (25 usuarios), sin facturación por mensaje. Fuentes: hexabot.ai
