Ajuste para dueños
Instalación
Guía de autoalojamiento en la documentación: dos aplicaciones, el builder y el viewer, más una base de datos Postgres; las guías de despliegue cubren Docker, Vercel y una instalación manual. La documentación indica que la nube administrada ahorra mucho tiempo de desarrollo. Fuentes: docs.typebot.com
Aprobación
No se documenta ningún paso de aprobación antes del envío. FAQ: el chat en vivo no es nativo; el traspaso a una persona está disponible mediante el bloque de Chatwoot. Fuentes: docs.typebot.com
Datos
Autoalojado: el builder, el viewer y la base de datos de resultados corren en tu servidor. Los bloques de IA envían prompts al proveedor de LLM cuya clave de API configures (bring your own LLM). Fuentes: docs.typebot.com, docs.typebot.com, chatbotscape.com
Costo
Autoalojado: sin cargo de licencia para uso interno (los costos de infraestructura y de API del LLM corren por tu cuenta). Cloud (visto el 2026-11-18): Free 200 chats/mes, Starter $39/mes (2,000 chats), $89/mes (10,000 chats). Fuentes: typebot.com
Comunidad
Typebot documenta una comunidad en Discord para conectar con otros usuarios. Fuentes: typebot.com
