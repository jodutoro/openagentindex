Ajuste para dueños
Instalación
Stack de Docker Compose (MySQL o PostgreSQL, Redis, Elasticsearch 8 y MinIO) iniciado con docker compose up -d --build; la guía indica cambiar la contraseña de administrador predeterminada y definir la dirección pública de almacenamiento, el secreto JWT y las claves de API de LLM y embeddings antes de salir a producción. Fuentes: github.com
Aprobación
sí — en un chat el agente puede proponer y editar tareas y ejecutarlas en modo de depuración, y completa el formulario mientras una persona decide; las notas de la versión v1.6.0 agregan intervención humana en el flujo (human-in-the-loop) y retroalimentación. Fuentes: github.com, github.com
Datos
Autoalojado: la plataforma y sus bases de datos corren en el host de quien lo opera, las credenciales de fuentes de datos y de IA se cifran con AES en la base de datos, y el código se ejecuta en un sandbox sin acceso a la red y con llamadas salientes limitadas a una lista de permitidos; las llamadas a modelos y embeddings van a los proveedores que defina quien lo opera. Fuentes: github.com, github.com, github.com
Costo
Gratis para autoalojar (MIT); quien lo opera paga el servidor (el stack incluye Elasticsearch) y el uso de API de LLM y embeddings; no hay una nube oficial documentada. Fuentes: github.com
