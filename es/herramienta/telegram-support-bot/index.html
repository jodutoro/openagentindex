Dónde está evaluada
  • Atención al cliente: posición 29, puntuación 53.8. Telegram Support Bot convierte cada mensaje de Telegram o Signal en un ticket dentro de un grupo del personal, y una integración opcional con un LLM responde automáticamente las preguntas frecuentes a partir de una base de conocimiento que aporta el operador, con triaje de IA (categoría, prioridad, resumen, sentimiento) y traducción de las respuestas del personal.
    Desglose de la puntuación: Evidencia de investigación 50 × 0.35; Ajuste para dueños 50 × 0.3; Salud del proyecto 45 × 0.25; Claridad de la licencia 100 × 0.1.
Ajuste para dueños
Instalación
Docker Compose (copia config/config-sample.yaml a config.yaml y define bot_token/staffchat_id/owner_id, luego docker compose up -d, que inicia el bot, MongoDB 8, signal-cli y, de forma opcional, mongo-express), o Node.js 24+ con una instancia de MongoDB (npm ci, npm run build, npm run prod). Fuentes: github.com
Aprobación
No documentado al 19 de noviembre de 2026
Datos
Autoalojado: el bot, los tickets y MongoDB se ejecutan en la infraestructura del operador, y el LLM se conecta a OpenAI o a cualquier endpoint compatible con OpenAI (LiteLLM, Ollama, vLLM) que el operador configure, por lo que los datos de los tickets pueden permanecer localmente. Fuentes: github.com
Costo
Gratis para autoalojar (GPL-3.0). Servicio alojado 'Botspace' desde EUR 4.99/mes (Starter), EUR 9.99/mes (Pro, incluye respuestas con IA en beta) y EUR 19.99/mes (Business), visto el 2026-11-18. Fuentes: botspace.bostrot.com, github.com
