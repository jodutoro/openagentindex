Ajuste para dueños
Instalación
docker-compose (recomendado), un chart de Helm (experimental) o instalación en Ubuntu/CentOS; MongoDB es obligatorio y Elasticsearch es opcional para la búsqueda de texto completo. Fuentes: github.com, docs.growi.org
Aprobación
No documentado al 18 de noviembre de 2026
Datos
Autoalojado; tú eliges el proveedor de IA y registras tu propia clave de API (OpenAI, Anthropic, Google, Azure OpenAI), y los permisos de acceso se comprueban en el momento de responder, de modo que nunca se usan páginas que no puedes ver. Fuentes: growi.org, docs.growi.org
Costo
Gratis para autoalojar bajo MIT; los planes alojados de growi.cloud parten de ¥8,000/mes (sin impuestos). Fuentes: growi.org, growi.cloud
