Los 'cerebros' por industria de SARA (agente de IA de WhatsApp) reservan y agendan: un cerebro de restaurante reserva mesas, uno de clínica agenda citas de pacientes y recopila formularios de ingreso, y otras verticales agendan clases, servicios y pruebas de manejo.

Instalación
Docker Compose: ejecuta git clone, copia .env.example a .env y define GROQ_API_KEY (u otro proveedor); luego ejecuta docker compose up -d; conecta WhatsApp escaneando un código QR. Fuentes: github.com

Datos
Autoalojado: el agente, el índice RAG de PostgreSQL/pgvector y la configuración se ejecutan en la infraestructura del operador; los datos personales (PII) se anonimizan antes de cualquier llamada a un LLM externo, y la autonomía es configurable (OFF/OBSERVE/SEMI-AUTO/FULL-AUTO). Fuentes: github.com
Costo
Gratis para autoalojar (AGPL-3.0). Existe una versión en la nube en get-scala.com; no había precios de planes en las páginas consultadas. Fuentes: github.com
