Dónde está evaluada
  • Seguimiento de clientes potenciales: posición 12, puntuación 75.0. Sellbird lee cada respuesta a sus correos de prospección, redacta una contestación, deja de lado las respuestas automáticas, respeta las bajas y pasa a una persona todo lo que no debería responder solo; por defecto retiene cada correo saliente en una Outbox hasta que una persona lo apruebe.
    Desglose de la puntuación: Evidencia de investigación 50 × 0.35; Ajuste para dueños 100 × 0.3; Salud del proyecto 70 × 0.25; Claridad de la licencia 100 × 0.1.
Ajuste para dueños
Instalación
Instalación con Python 3.11+ (pip install -e . en un virtualenv) con una CLI de Claude Code con sesión iniciada (Claude Pro o Max) o un plan de ChatGPT con la CLI de Codex, un buzón de envío (Gmail, Microsoft 365 o SMTP) y calentamiento (warmup); se documenta una configuración con Docker Compose solo para Linux nativo, y el README ofrece una configuración guiada con Claude Code. Fuentes: github.com, github.com
Aprobación
sí — todo correo saliente, incluidas las respuestas redactadas, espera en la Outbox la aprobación de una persona hasta que el dueño active el piloto automático; esto es lo predeterminado en la aplicación autoalojada gratuita. Fuentes: github.com, github.com
Datos
Corre en la máquina o el servidor del propio operador, con su base de datos y sus registros en una carpeta de datos local y un panel enlazado a 127.0.0.1; las llamadas a modelos pasan por la suscripción de Claude Code o Codex del propio operador, y Docker está documentado solo para Linux nativo. Fuentes: github.com, github.com
Costo
El software es gratis (AGPL-3.0); no hay factura de API de modelos porque corre con un plan existente de Claude Pro/Max o ChatGPT; encontrar negocios cuesta $0 con la fuente OpenStreetMap por defecto (las fuentes de pago, desde unos $0.37 por 1,000), y un buzón de Google Workspace cuesta unos $7 al mes (README, visto el 2026-11-18). Fuentes: github.com
