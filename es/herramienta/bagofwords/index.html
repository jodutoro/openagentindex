Bag of Words conecta un LLM con las bases de datos, almacenes de datos y aplicaciones de negocio de una organización; los agentes hacen preguntas y generan consultas, gráficos, informes y paneles a partir de esos datos, con informes programados, y los cambios de instrucciones que superan la evaluación quedan retenidos para que una persona los revise y los promueva.

Ajuste para dueños
Instalación
Un solo comando docker run (docker run -p 3000:3000 bagofwords/bagofwords), o Docker Compose / Helm; también se ofrecen paquetes para entornos aislados de internet (air-gapped). Fuentes: docs.bagofwords.com
Aprobación
sí — el ciclo de automejora retiene los cambios de instrucciones de los agentes que superan la evaluación para que una persona los revise y los promueva en lugar de aplicarlos automáticamente, y la plataforma ofrece aprobaciones y registros de auditoría. Fuentes: docs.bagofwords.com
Datos
Autoalojado: el operador ejecuta la aplicación en su propia infraestructura y conecta sus propias fuentes de datos y claves de API de LLM; se captura telemetría básica de uso a menos que se desactive en bow-config.yaml. Fuentes: github.com, docs.bagofwords.com
Costo
Autoalojado es gratis (núcleo AGPL-3.0); el operador aporta sus propias claves de API de LLM y su infraestructura, y una licencia Enterprise añade controles de gobernanza y escala. No hay oferta de nube oficial. Fuentes: docs.bagofwords.com
