Ajuste para dueños
Instalación
Aplicación PHP (PHP 8.2+, MySQL): clona el repositorio e instala con composer, o descarga una versión publicada (no necesita composer); también hay una imagen de Docker (docker-standalone) y una aplicación de un clic en DigitalOcean. Fuentes: github.com
Aprobación
No documentado al 2026-11-18
Datos
Autoalojado en el servidor del operador (PHP/MySQL), así que los datos del chat permanecen en la infraestructura del operador; la IA se integra conectando el proveedor propio del operador (OpenAI, Ollama, Gemini, Rasa). Fuentes: github.com, livehelperchat.com
Costo
Gratis para autoalojar (Apache-2.0); la página de inicio afirma 'Enterprise level features free to use for everyone everywhere'. Fuentes: livehelperchat.com, github.com
Comunidad
Discord (https://discord.gg/YsZXQVh), GitHub Discussions (https://github.com/LiveHelperChat/livehelperchat/discussions) y foro (http://forum.livehelperchat.com/). Fuentes: github.com
