Ajuste para dueños
Instalación
Un solo comando con pip/uvx o Docker; la documentación ofrece una imagen :main y una imagen :slim (descarga de 197 MB, unos 300 MiB de RAM en reposo en la prueba del proyecto) para despliegues escalables. Fuentes: docs.openwebui.com
Aprobación
Sí: con Tool Permissions activado por un administrador, las llamadas a herramientas pueden ejecutarse en modo 'Ask for approval' (Allow/Deny antes de que el modelo continúe) o en modo 'Auto', donde una política decide qué llamadas necesitan aprobación. Fuentes: docs.openwebui.com
Datos
Autoalojado y hecho para funcionar sin conexión con Ollama o con APIs compatibles con OpenAI; los documentos pueden quedarse en tu propia base de datos vectorial externa. Los modelos en la nube que conectes reciben los prompts que envíes. Fuentes: docs.openwebui.com, docs.openwebui.com
Costo
Gratuito para autoalojar (la infraestructura y los costos de API de modelos corren por tu cuenta). El LICENSE menciona una licencia Enterprise para cambios de marca con más de 50 usuarios; no se publica ningún precio. Fuentes: github.com, openwebui.com
Comunidad
Open WebUI documenta Discord y GitHub Discussions como canales públicos de ayuda, con un canal #questions en Discord para respuestas rápidas. Fuentes: docs.openwebui.com
