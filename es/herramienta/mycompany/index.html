Dónde está evaluada
  • Administración y facturación: posición 11, puntuación 71.3. MyCompany es un ERP de código abierto cuya pantalla de Bills tiene una acción Import (GPT) que lee con OpenAI el archivo de un documento de proveedor y completa el encabezado de la factura (número, fechas, proveedor, moneda) y sus líneas (artículo, cantidad, precio, impuestos) a partir de los datos maestros existentes, y deja la factura en Draft para que una persona la revise y corrija antes de marcarla como To pay.
    Desglose de la puntuación: Evidencia de investigación 50 × 0.35; Ajuste para dueños 100 × 0.3; Salud del proyecto 55 × 0.25; Claridad de la licencia 100 × 0.1.
Ajuste para dueños
Instalación
Docker Compose con cuatro contenedores (PostgreSQL, servidor de aplicación, MyCompany, cliente web) desde un compose.yaml en el servidor de descargas de lsFusion, o un script de instalación para Linux o un instalador para Windows; se recomiendan 4 GB de RAM; la importación de facturas con GPT además necesita una clave de API de OpenAI y un prompt de reconocimiento en el tipo de factura. Fuentes: mycompany-docs.lsfusion.org, github.com, github.com
Aprobación
sí — una factura importada se crea como Draft, que una persona revisa y ajusta, y pasa a To pay solo mediante la acción Mark as Todo; los valores que no pueden asociarse con los datos maestros existentes quedan vacíos. Fuentes: github.com
Datos
Los datos del ERP permanecen en el PostgreSQL de quien lo opera; solo el documento de proveedor enviado para la importación con GPT va a OpenAI, con la clave de API propia de quien lo opera, y la importación se omite con un mensaje si falla la clave o la solicitud. Fuentes: github.com, github.com, mycompany-docs.lsfusion.org
Costo
Apache-2.0 sin cargos de licencia; quien lo opera paga el servidor y el uso de la API de OpenAI en las importaciones con GPT. Fuentes: mycompany.lsfusion.org, github.com
