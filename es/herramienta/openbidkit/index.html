  • Informes y contenido: posición 7, puntuación 79.3. OpenBidKit es una herramienta de escritorio que lee un documento de licitación cargado, genera un esquema y el texto de la propuesta con un modelo de lenguaje configurado (APIs compatibles con OpenAI o modelos locales mediante Ollama o LM Studio), revisa si hay texto duplicado y riesgos de rechazo, y exporta a Word; los esquemas y el contenido generado siguen siendo editables para su revisión humana.
    Desglose de la puntuación: Evidencia de investigación 75 × 0.35; Ajuste para dueños 60 × 0.3; Salud del proyecto 100 × 0.25; Claridad de la licencia 100 × 0.1.
Ajuste para dueños
Instalación
Descarga el instalador o ejecutable de las versiones publicadas del proyecto y ejecútalo (aplicación de escritorio hecha con Electron); el operador ingresa su propia clave de API del modelo en la configuración; no necesita servidor. Fuentes: github.com
Aprobación
No documentado al 19 de noviembre de 2026
Datos
Se ejecuta como aplicación de escritorio en la computadora del propio usuario; el texto de la licitación y los prompts van al proveedor de modelos que el usuario configure, o se quedan en la computadora cuando se usa un modelo local; existe un servicio alojado aparte en yibiao.pro. Fuentes: github.com, yibiao.pro
Costo
Software gratuito (AGPL-3.0); el usuario paga solo el uso de la API del modelo (el README cita unos CNY 1.03 por una propuesta de 110,000 palabras con un modelo); el servicio alojado yibiao.pro vende paquetes prepagados. Fuentes: github.com, yibiao.pro
Comunidad
Canal de Telegram enlazado desde el README (t.me/OpenBidKit), además de GitHub Issues y una dirección de correo. Fuentes: github.com
