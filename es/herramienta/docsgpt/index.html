Ajuste para dueños
Instalación
Un solo comando (curl -fsSL https://docs.ac/install | bash) instala la CLI docsgpt y ejecuta docsgpt up, que inicia el stack con Docker Compose (Postgres y Redis incluidos); requiere Docker con Compose 2.24 o posterior. La página comunitaria de autoalojamiento calcula 2 GiB de RAM para un usuario y 4 GiB para hasta 10 usuarios concurrentes. Fuentes: docs.docsgpt.cloud, docs.docsgpt.cloud, docsgpt.cloud
Aprobación
sí — en la versión autoalojada bajo MIT, una acción de herramienta (por ejemplo, una acción de escritura de una herramienta de API) puede configurarse para pausar al agente y pedir a una persona que la apruebe antes de ejecutarse; el interruptor viene desactivado por defecto, y las ejecuciones por clave de API, widget, webhook o programadas no pueden aprobar, por lo que omiten o rechazan las acciones sujetas a aprobación. Las respuestas del chat no se retienen para aprobación por defecto. Fuentes: docs.docsgpt.cloud, docs.docsgpt.cloud, docs.docsgpt.cloud
Datos
Se ejecuta en el entorno propio del dueño (Docker, Kubernetes o aislado de la red); con un servidor de modelos local como Ollama o vLLM ningún documento ni pregunta sale de la red, y con un proveedor de modelos en la nube el texto recuperado se envía a ese proveedor. Fuentes: docsgpt.cloud, docs.docsgpt.cloud
Costo
Gratuito para autoalojar bajo MIT, con usuarios ilimitados y soporte de la comunidad; la versión Cloud alojada cuesta $20 por usuario al mes, Managed desde $2,000 al mes, y los servicios de soporte On-premises o Air-gapped desde $10,000 (consultado el 2026-11-18). Fuentes: docsgpt.cloud, docsgpt.cloud
Comunidad
Servidor de Discord enlazado desde el README y el encabezado de la documentación para pedir ayuda y conversar; el soporte comunitario de la edición autoalojada se indica en la página de autoalojamiento. Fuentes: discord.gg, github.com, docsgpt.cloud
