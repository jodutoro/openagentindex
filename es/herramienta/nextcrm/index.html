Instalación
Docker Compose incluye la aplicación, PostgreSQL con pgvector, MinIO e Inngest: copia .env.docker a .env y ejecuta docker compose up -d; el enriquecimiento con IA y las integraciones de correo requieren las claves propias del operador de OpenAI, Anthropic, Firecrawl, E2B o Resend. Fuentes: github.com
