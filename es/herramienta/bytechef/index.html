Ajuste para dueños
Instalación
Un solo docker run con una base de datos H2 embebida para evaluación, o docker compose up con PostgreSQL (recomendado; la base de conocimiento y Copilot necesitan PostgreSQL con pgvector); la guía de autoalojamiento describe una instalación manual con Docker y opciones tipo Kubernetes. Fuentes: github.com, docs.bytechef.io
Aprobación
sí — el componente Approval (Human-in-the-Loop) pausa un flujo para que una persona apruebe, descarte o complete un formulario corto, puede usarse como herramienta de un agente de IA, y la página de Enterprise no lo lista como función Enterprise. Fuentes: docs.bytechef.io, docs.bytechef.io
Datos
Los datos autoalojados se guardan en tu propia base de datos (H2 embebida o PostgreSQL) con claves de cifrado generadas en la carpeta montada ~/.bytechef; las llamadas de IA van al proveedor de modelos que conectes, o a un Ollama local sin clave. Fuentes: github.com
Costo
El núcleo es gratis para autoalojar; ByteChef Cloud alojado cuesta $23/mes (Starter, 5,000 tareas) o $135/mes (Growth) en la página de precios, y el autoalojamiento con SSO, roles y funciones similares se vende bajo Enterprise a solicitud. Fuentes: bytechef.io
Comunidad
Discord (https://discord.gg/VKvNxHjpYx) y GitHub issues, listados en el README y en docs.bytechef.io. Fuentes: github.com, docs.bytechef.io
