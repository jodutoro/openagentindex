How the index is made

Collected
2026-11-18

Research-based — not yet hands-on tested

Method by Jonathan Duque

Collection date: 2026-11-18.

The v1 ranking is research-based: public documentation, repository data, licence files and independent reviews. No hands-on tests have been run yet; the planned protocol is below.

Data is collected by scripts and AI research assistants working to this method, from the public sources linked in every row; scores come from the formula on this page. Report errors through the correction path.

Inclusion and labels

A tool must document the named job with a first-party source, be self-hostable, have a release within six months, pass the repository-health and licence gates, and meet the page minimum. Unknown evidence stays unknown. OSI-approved open source, fair-code, source-available and mixed are distinct labels; open source is used only for OSI-labelled tools.

Some ranked tools have no built-in AI feature. They are included because their documentation covers the business job and they expose an API that an agent can drive; each is tagged in its row.

Weights and formula

Score component weights
ComponentWeight
Research evidence35%

Project health25%
Licence clarity10%

The displayed score is the weighted total, rounded half up to one decimal. Ties use research evidence, owner fit, project health and licence clarity in that order; exact ties share a rank. Bands are fixed and global: a tool's score does not move when another tool joins the list, and the star counts are shown but not scored.

How each component is scored

Every sub-score is a whole number. The full rules are summarised here so that anyone can re-compute one row.

Gates: the minimum evidence to be ranked

A tool is ranked in a function only if it passes every gate. A failure is recorded and the tool is not shown with a score for that function.

GateRule
G1 ListedThe tool is in the index and not on the excluded list.
G2 Job documentedThe function is one the tool lists, with a sentence on what it does for that job and at least one first-party source.
G3 Self-hostable and releasedThe tool can be self-hosted and has a release within six months. All four licence classes are eligible and labelled exactly.
G4 Licence labelThe class is OSI, fair-code, source-available or mixed, with a licence name and a source. An OSI class needs exactly one licence ID approved on the SPDX list (3.29.0); fair-code and source-available must have no OSI-approved ID.
G5 Health dataGitHub data for the right repository, with a last commit date.
G6 ReleasesAt least one release in the last 180 days, or the project does not publish GitHub releases (then G3 decides).
G7 Not archivedThe repository is not archived.
G8 Same repositoryGitHub reports the same repository name that the index lists.
G9 Page minimumA function shows ranks only if at least 3 tools pass G1 to G8.

A first-party source is a page on the tool's own site (homepage, documentation or self-hosting page) or in its GitHub repository.

Hands-on protocol

Hands-on tests are planned; no date is set. Each function will get one realistic owner task, run the same way on every ranked tool. Pass/fail checks are published before any run. Each run pins the tool version, container image, AI model and date; uses sample data only; runs three times; and publishes results with logs.

Panel method

The panel is reported, never scored. It holds 22 answers in total, all collected on 2026-11-18, from free consumer interfaces: Gemini in a logged-in consumer account in temporary chat, Gemini in the logged-out web app, and Perplexity in the logged-out web app (including one logged-out session with the interface served in Spanish from a Colombia IP). Perplexity's logged-in route was not available. No ChatGPT or Google AI Overview answers were collected: ChatGPT showed a Cloudflare check and Google AI Overview had no human-driven session. For each function the page gives one line per engine and interface with its own number of answers and date, says in how many of each interface's answers a tool from the index was named ("named in k of n answers", counted per interface and never pooled or given as a percentage), and lists the engines that were not collected with the reason. Answers collected while logged in to a consumer account may be personalised: the logged-in Gemini answers came from Jonathan Duque's own account, which has prior chat history on related topics, so they are not a neutral sample, and the page says so. A function with no answers shows which engines are pending.

Independence

Jonathan Duque works at an SEO software company. Open Agent Index is his personal project: his employer has no role in what is included or how it is scored, and none of its products is ranked.

Sources and attribution

Repository figures (stars, release and commit dates) were read from the GitHub API on 2026-11-18. Open Agent Index is not affiliated with or endorsed by GitHub.

Corrections

Maintainers can request a correction to a value, source or label through GitHub issues, using the correction template: the page URL, the value, a source that shows the correct value, and a label. Jonathan Duque reviews each request against the cited source; a request does not guarantee a changed result. Accepted corrections are dated in the change log on this page.
